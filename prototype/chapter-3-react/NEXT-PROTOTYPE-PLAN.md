# План следующего прототипа §11

**Статус:** согласован и реализован 16 октября 2026 года.

## Правило работы над прототипом

До реализации фиксируются:

1. вопрос, на который должен ответить прототип;
2. содержание параграфов, одинаковое для всех вариантов;
3. структурно разные варианты и гипотеза каждого из них;
4. критерии сравнения вариантов.

Варианты обсуждаются с пользователем до написания интерфейса. Вариант не может отличаться от другого только цветом, формулировками или размером элементов.

## Вопрос прототипа

Какая структура страницы помогает понять тему §11 «Показательная функция», исследуя все осмысленные параметры анимации рядом с самой анимацией?

## Что проверяется

- иерархия учебной информации;
- расположение введения, объяснения, анимации, её параметров и проверки;
- пригодность структуры для определения, свойств, графика и проверки понимания внутри одного параграфа;
- возможность исследовать все осмысленные параметры показательной функции без перегрузки страницы.

## Что не проверяется

- обязательное прохождение и блокировка материала;
- хранение прогресса;
- оценивание ученика;
- производственная архитектура приложения;
- окончательная редактура всего учебного текста.
- содержание и анимации §§12–19;
- навигация между параграфами главы.

## Структура книги

- Книга посвящена алгебре и началам математического анализа за 11 класс.
- Книга состоит из глав.
- Глава 3 посвящена показательной и логарифмической функциям.
- Глава 3 состоит из §§11–19.
- Следующий прототип реализует только §11 «Показательная функция».
- Остальные параграфы остаются в книге, но не входят в объём этого прототипа.

## Инварианты всех вариантов

### Границы параграфа

- Прототип содержит только §11 и не имитирует ещё не созданные параграфы.
- В прототипе нет состояний «закрыт», «пройден» или «доступен после предыдущего».
- При переключении варианта параметры анимации сохраняются, чтобы сравнивать одно и то же состояние §11.

### Учебная иерархия

- Главный заголовок страницы — название текущего параграфа.
- Название главы и номер параграфа являются служебной навигационной информацией и не конкурируют с темой.
- Крупный размер используется только для основного понятия или центральной формулы.
- Декоративные показатели вроде «девять параграфов» или «пять режимов» не выводятся крупным текстом.
- Введение каждого параграфа состоит не более чем из двух фактических предложений: новый объект и изучаемый вопрос.

### Анимация и её параметры

- У каждого параграфа собственная анимация или интерактивный пример, соответствующие его теме.
- Один параграф не использует общий график всей главы.
- На настольном экране параметры анимации находятся непосредственно справа от неё внутри одного визуального блока.
- На узком экране параметры располагаются сразу после анимации, без промежуточного текста.
- Логарифм, логарифмическая функция и производная не входят в §11 и не показываются.

## Содержание параграфа

### §11. Показательная функция

- **Исходное знание:** свойства степеней и координатная плоскость.
- **Новый объект:** функция `y = aˣ`, где `a > 0` и `a ≠ 1`.
- **Учебная цель:** связать значение основания с областью значений, опорной точкой и монотонностью.
- **Представление:** только семейство показательных графиков.
- **Параметры анимации:** основание `a`, аргумент отмеченной точки `x`, отображение точки `(0; 1)`, асимптоты `y = 0` и таблицы значений. Ученик может менять все параметры, имеющие смысл для текущего объяснения.
- **Не показывать:** логарифм и логарифмический график.

## Три сравниваемых варианта

Все варианты используют одинаковые тексты, формулы, примеры, параметры анимации и математические состояния. Сравнивается только структура страницы и способ ведения внимания.

### Вариант A. Разворот книги

**Гипотеза:** знакомая структура «объяснение слева, материал справа» позволит читать параграф как книгу и сразу проверять утверждения в анимации.

**Компоновка настольного экрана:**

```text
┌──────────────────────────────────────────────────────┐
│ Книга / Глава 3 / §11                                │
├───────────────┬──────────────────────┬───────────────┤
│ название      │ анимация / пример    │ параметры     │
│ введение      │                      │ анимации      │
│ определение   │                      │ состояние     │
│ свойства      │                      │                │
├───────────────┴──────────────────────┴───────────────┤
│ разобранный пример или проверка понимания            │
└──────────────────────────────────────────────────────┘
```

**Главное действие:** читать утверждение слева и сразу проверять его в анимации.

**Сильная сторона:** высокая информационная плотность и сходство с книгой.

**Риск:** текст может конкурировать с анимацией за внимание.

### Вариант B. Параграф с основной анимацией

**Гипотеза:** если анимация занимает основную часть экрана, ученик сначала обнаружит закономерность, а затем прочитает краткую формулировку.

**Компоновка настольного экрана:**

```text
┌──────────────────────────────────────────────────────┐
│ Книга / Глава 3 / §11                                │
├──────────────────────────────────────────────────────┤
│ §11. Показательная функция                           │
│ краткое введение и один исследовательский вопрос     │
├──────────────────────────────────┬───────────────────┤
│                                  │ параметры         │
│ крупная анимация / пример        │ анимации          │
│                                  │ текущее состояние │
├──────────────────────────────────┴───────────────────┤
│ сформулированное правило       │ быстрая проверка    │
└──────────────────────────────────────────────────────┘
```

**Главное действие:** менять все доступные параметры анимации, которые имеют математический смысл в текущем объяснении, и сопоставлять их с изменениями функции.

**Сильная сторона:** минимальное расстояние между действием и математическим следствием.

**Риск:** одного экрана может не хватить для определения, всех свойств и разобранного примера.

### Вариант C. Последовательный параграф

**Гипотеза:** линейный порядок «определение → пример → эксперимент → вывод» лучше подходит для первого знакомства, чем одновременный показ всей информации.

**Компоновка настольного экрана:**

```text
┌──────────────────────────────────────────────────────┐
│ Книга / Глава 3 / §11                                │
├──────────────────────────────────────────────────────┤
│ название и отдельное введение                        │
├──────────────────────────────────────────────────────┤
│ определение и исходный пример                        │
├──────────────────────────────────┬───────────────────┤
│ анимация / преобразование        │ параметры         │
├──────────────────────────────────┴───────────────────┤
│ вывод, типичная ошибка и проверка понимания          │
└──────────────────────────────────────────────────────┘
```

**Главное действие:** последовательно читать один параграф сверху вниз.

**Сильная сторона:** причинный порядок объяснения и достаточно места для определения, свойств и примера §11.

**Риск:** для возвращения от вывода к анимации потребуется прокрутка, хотя её параметры никогда не отделяются от самой анимации.

## Что именно различается

| Решение | Вариант A | Вариант B | Вариант C |
| --- | --- | --- | --- |
| Основная структура | Разворот книги | Параграф с основной анимацией | Последовательный параграф |
| Первый объект внимания | Объяснение | Анимация | Определение |
| Плотность информации | Высокая | Низкая | Средняя |
| Основная работа внутри параграфа | Сопоставление колонок | Изменение параметров анимации | Чтение сверху вниз |
| Положение параметров | Справа от анимации | Справа от анимации | Справа от анимации |
| Объём | Только §11 | Только §11 | Только §11 |

## Критерии сравнения

1. За пять секунд понятно, какой параграф открыт и что в нём изучается.
2. Главная математическая мысль визуально важнее служебной информации.
3. Параметры воспринимаются как часть анимации и не требуют отдельной прокрутки.
4. В §11 нет логарифма, производной и других понятий следующих параграфов.
5. Анимация объясняет свойства показательной функции, а не пытается представить всю главу.
6. После взаимодействия можно сформулировать одно конкретное правило параграфа.
7. Переключение между вариантами сохраняет все параметры анимации.

## Результат ревью

Выбран вариант C «Последовательный параграф». Он лучше остальных поддерживает последовательное чтение и не ставит пример на один уровень с основным определением.

## Итерация распространения на главу 3

**Статус:** реализована 16 октября 2026 года.

Эта итерация не выбирает новую компоновку. Она проверяет, масштабируется ли уже выбранный вариант C на §§11–19 без смешения тем и без копирования компонентов для каждого параграфа.

### Цель

Собрать целостную главу, в которой каждый параграф имеет собственное введение, пример, тематическую анимацию, свойства и проверку понимания, а ученик может открыть любой материал через оглавление.

### Варианты представления материала

- функция — интерактивный график с чтением координат;
- уравнение — точка пересечения графика с заданным уровнем;
- неравенство — граница и область решений на оси;
- определение логарифма — перевод между степенной и логарифмической записью;
- свойства логарифмов — числовая проверка равенства двух записей;
- производная — график, касательная и её наклон.

Тип представления выбирается по теме параграфа. Один общий график для всей главы не используется.

### Навигация

- оглавление содержит названия глав и параграфов книги;
- хлебные крошки содержат только книгу и текущий параграф;
- название книги открывает оглавление;
- §§11–19 реализованы и доступны без ограничений;
- переход в другую главу открывает плейсхолдер.

### Источник содержания

Скан книги используется только для структуры оглавления. Определения и формулы берутся из открытых учебных источников и перечисляются в `README.md` прототипа. Распознавание страниц книги не выполняется.
