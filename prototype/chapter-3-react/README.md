# Прототип §11 «Показательная функция»

React-прототип одного параграфа учебника. Он сравнивает три структуры страницы при одинаковом учебном содержании и одинаковом состоянии интерактивной анимации.

## Запуск

Нужен Node.js 20 или новее.

Из корня проекта:

```sh
npm install
npm run dev
```

Команды одинаковы для Windows, macOS и Linux. После запуска нужно открыть адрес, который напечатает Vite.

## Варианты прототипа

- `?variant=A` — разворот книги: объяснение слева, анимация и параметры справа;
- `?variant=B` — основная анимация: сначала исследование, затем формулировка свойств;
- `?variant=C` — последовательный параграф: определение, пример, исследование и вывод сверху вниз.

Переключатель вариантов находится внизу экрана. Стрелки клавиатуры переключают варианты, если фокус не находится на элементе управления.

Состояние можно воспроизвести через параметры адреса:

```text
?variant=B&base=0.5&x=1&anchor=1&asymptote=1&table=0
```

## Параметры анимации

- основание `a` от `0.2` до `4`, включая граничный случай `a = 1`;
- аргумент `x` отмеченной точки от `-2` до `2`;
- отображение общей точки `(0; 1)`;
- отображение асимптоты `y = 0`;
- отображение таблицы значений.

## Сборка

Из корня проекта:

```sh
npm run build
```

В прототипе намеренно нет содержания других параграфов, хранения прогресса, блокировки материала и производственной маршрутизации.
