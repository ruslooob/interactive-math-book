# Прототип §11 «Показательная функция»

React-прототип одного параграфа учебника. Текущая итерация основана на выбранной компоновке «Последовательный параграф»: введение, определение, интерактивная анимация, свойства, пример и проверка понимания.

## Запуск

Нужен Node.js 20 или новее.

Из корня проекта:

```sh
npm install
npm run dev
```

Команды одинаковы для Windows, macOS и Linux. После запуска нужно открыть адрес, который напечатает Vite.

## Взаимодействие

- основание `a` изменяется ползунком или одной из заготовок;
- наведение или касание графика показывает координаты соответствующей точки;
- таблица значений пересчитывается при изменении основания;
- произвольное значение `x` можно ввести в поле и сразу получить `y`;
- проверка понимания показывает по одному вопросу и завершает последовательность итоговым результатом.

Состояние основания воспроизводится через параметр адреса, например:

```text
?base=0.5
```

## Сборка

Из корня проекта:

```sh
npm run build
```

В прототипе намеренно нет содержания других параграфов, хранения прогресса, блокировки материала и производственной маршрутизации.

Общие выводы ревью записаны в `docs/LEARNING-DESIGN-RULES.md`. Три исходных варианта компоновки сохранены в истории Git в коммите `63917d2`.
