# Прототип «Глава 3: экспонента и логарифм»

Интерактивный React-прототип для проверки трёх способов расположить материал §§11–19.

## Запуск

Нужен Node.js 20 или новее.

Из корня проекта:

```sh
npm install
npm run dev
```

Команды одинаковы для Windows, macOS и Linux. После запуска откройте адрес, который напечатает Vite.

## Варианты

- `?variant=A` — карта главы, график и объяснение одновременно;
- `?variant=B` — широкий атлас с последовательностью параграфов;
- `?variant=C` — сравнительная лаборатория с двумя семействами функций.

Переключатель вариантов находится внизу экрана. Стрелки клавиатуры переключают варианты без перезагрузки.

Для быстрой проверки конкретного состояния можно добавить параметры `section` и `base`, например `?variant=A&section=18&base=0.5`.

## Сборка

Из корня проекта:

```sh
npm run build
```

Это исследовательский прототип: в нём намеренно нет хранения прогресса, маршрутизации курса и тестовой инфраструктуры.
