# Learning materials

The repository keeps derived text materials needed for reproducible development. These include tables of contents, section titles, and recorded links to open textbook sources. The files remain available without the original scans and are reviewed with the other project documentation.

Original textbook scans are kept only on local machines when there is lawful access. They are not part of the repository and are not needed to install dependencies, run the MVP, or build it. Specific rules in `.gitignore` ignore them. A new rule must name a specific file so that it does not hide PDF documents that the project intentionally publishes.

When updating a derived material, record the source name and page so that someone can check the result. Do not copy scan content into the repository without a separate legal basis.
