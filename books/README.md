# Учебные материалы

В репозитории хранятся производные текстовые материалы, необходимые для воспроизводимой разработки: оглавления, названия разделов и зафиксированные ссылки на открытые учебные источники. Такие файлы доступны без исходных сканов и проверяются вместе с остальной документацией проекта.

Исходные сканы учебников хранятся только локально при наличии законного доступа. Они не входят в репозиторий, не требуются для установки зависимостей, запуска или сборки MVP и игнорируются точечными правилами в `.gitignore`. Новое правило должно указывать конкретный файл, чтобы не скрывать PDF-документы, которые проект намеренно публикует.

При обновлении производного материала в нём указываются имя исходника и страница, по которой можно проверить результат. Содержимое скана не копируется в репозиторий, если для этого нет отдельного правового основания.
