# Доменная документация

Проект использует единый доменный контекст.

## Что читать перед исследованием проекта

- `GLOSSARY.md` — термины предметной области.
- `docs/adr/` — архитектурные решения, относящиеся к изменяемой части проекта.

Если файла нет, работу следует продолжить без требования создать его заранее. Новые термины и решения фиксируются тогда, когда они действительно появляются.

## Структура

```text
/
├── GLOSSARY.md
├── docs/
│   └── adr/
└── app/
```

## Использование терминов

В задачах, спецификациях, тестах и коде следует использовать термины из `GLOSSARY.md`. Если подходящего термина нет, нужно проверить, является ли это новым понятием или случайным синонимом существующего.

## Конфликты с ADR

Если предлагаемое изменение противоречит существующему ADR, конфликт указывается явно. Решение нельзя молча заменить новым.
