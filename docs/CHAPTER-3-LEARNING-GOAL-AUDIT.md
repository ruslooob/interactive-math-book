# Аудит учебных целей главы 3

Проверка сопоставляет учебную цель каждого параграфа с его текущим содержанием и интерактивом. Аудит выполнен после согласования структуры §12: формы задач → методика решения → тренажёры → самопроверка.

| --- | --- | --- | --- | --- |

## Вывод

Параграфы §§11, 14 и 15 уже построены для введения понятий. §12 построен для развития навыка. Параграфы §§13, 16–19 пока смешивают цель «научить решать» с интерактивами, которые преимущественно объясняют математическую зависимость. Их следует перерабатывать отдельными итерациями, начиная с методики решения и набора навыков для тренажёров.

Порядок дальнейшей работы: §13 → §16 → §17 → §18 → §19. Такой порядок сохраняет последовательность книги и позволяет сначала проверить шаблон для неравенств, затем распространить его на логарифмические задачи и дифференцирование.
