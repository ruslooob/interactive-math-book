# Скиллы проекта

Каталог содержит скиллы, доступные любому агенту или человеку, работающему с проектом.

## Запуск

Запись `/name` или требование вызвать скилл означает: прочитать `.agents/skills/name/SKILL.md` и выполнить описанный процесс, если такой каталог существует.

- Если среда предоставляет механизм скиллов, использовать его.
- Если такого механизма нет, открыть `SKILL.md` напрямую.
- Человек выполняет те же шаги по документу.
- Если среда поддерживает параллельных агентов, независимые задачи можно выполнять параллельно. В остальных средах выполнять их последовательно, сохраняя те же границы задач и критерии завершения.

Два обозначения в импортированных текстах описывают действия среды, а не проектные скиллы:

- `/clear` — начать новую сессию без истории текущего разговора;
- `/compact` — составить краткое резюме релевантного контекста и продолжить с ним в новой сессии.

Если среда не предоставляет одноимённую команду, агент или человек выполняет указанное действие доступным способом.
